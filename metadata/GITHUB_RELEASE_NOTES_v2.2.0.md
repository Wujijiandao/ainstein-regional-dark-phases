### Scientific change
The new audit extends the local reciprocal-feedback sign restriction to stable shared Gaussian controls and separates two distinct ideas: passive shared mediation, which remains cooperative after exact elimination, and an externally imposed/global conserved phase budget, which can constrain abundance but is predictive only if the relevant budget follows independently from microscopic carrier/geometry physics.

### Scope
No completed microscopic abundance prediction is claimed. The remaining routes require a derived repulsive/non-Gaussian global response, a derived conserved even budget, measured higher-order saturation, or genuine nonequilibrium feedback.
