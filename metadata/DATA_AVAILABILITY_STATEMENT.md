# Data Availability statement

> The galaxy diagnostic uses the publicly available SPARC radial-acceleration data described by Lelli, McGaugh and Schombert and by McGaugh, Lelli and Schombert. No new observational data were generated. Synthetic fields and numerical tables used in the stress tests are regenerated deterministically from the archived code and fixed random seeds. The GitHub-safe software release does not redistribute the third-party SPARC table; it provides a retrieval helper and records the expected source snapshot for reproducibility.
