# v1.0.0 — Communications Physics submission release

First stable research release supporting the manuscript **“Regional gravitational phases as an effective framework for dark-sector unification.”**

Highlights:

- freezes the regional expansion–density and matter–geometry selector calculations;
- includes first-passage and power-spectrum obstruction audits;
- implements maximal-basin antichain and history-dependent phase occupation tests;
- reproduces diffuse-interface, coarsening, thin-wall and finite-size phase results;
- reproduces the geometric active-charge diagnostics and SPARC fit;
- adds a deterministic 3D Gaussian/watershed stress test showing that an instantaneous single-scale basin catalogue yields only a small finite-size-active V fraction;
- includes 28 regression tests, release metadata and SHA-256 manifest.

The 3D synthetic test is not an N-body prediction. The theory remains an effective framework; its covariant phase dynamics, primordial parent content, absolute vacuum scale and phase-field gradient stiffness are not microscopically derived.
